# Мои деньги 2.2 — проверка Android без риска для 2.0

**Отдельный пакет**: `kg.evgeny.moidengi.sheets.next`, который устанавливается рядом с `kg.evgeny.moidengi.sheets` (версия 2.0). Не удалять 2.0.

- Исправлен поворот, Android 15 safe insets, ограничены внешние страницы WebView.
- Приложение открывает локальный интерфейс; вход в закрытую Google Таблицу через Google Play Services AuthorizationClient.
- Android Google OAuth для нового пакета требует отдельный Google Cloud Android OAuth client с SHA1 **релизного** сертификата.
- Приложение не проверено в Google OAuth под новым сертификатом, пока новый Android client не зарегистрирован.
- GitHub Actions выпускает только **временный debug APK как тестовый артефакт**. Финальный APK подписывается **постоянным закрытым ключом вне публичного репозитория**, после проверки APK Android SDK apksigner; этот ключ нельзя публиковать в репозитории.
- Официальные системные тесты с эмулятором API 35 проверяют запуск, поворот и отсутствие пустого экрана. Для теста эмулятора Google Play Services отключаются, поэтому OAuth проверяется отдельно.
- Исходные семейные расходы остаются в частной Google Таблице. Никаких токенов/ключей финансового доступа в APK.

**Текущую 2.0 не удалять**, пока новая версия не прочла реальные расходы с Google.
