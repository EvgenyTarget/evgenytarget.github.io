# Мои деньги — один учёт, одна таблица, без GitHub в цепочке данных

**Активная схема:** ChatGPT (текст/фото чеков) → закрытая Google Таблица → Android 2.0 (Google Sheets API + официальный OAuth Google). 
GitHub используется ТОЛЬКО для исходного кода и редкой сборки APK, но не для расходов, синхронизации, снимков и ключей.

## При расходе из чата
1. Определи платёж/возврат/перевод между своими счетами/список будущих покупок. Для чека выясни реальный оплаченный итог с учётом скидки/НДС, не суммируй итог повторно.
2. Валюта KGS, VND, USD, KZT. Сохраняй исходные суммы. Эквивалент в KGS — банковское списание при наличии либо проверенный курс на дату с пометкой оценочности. Не выдумывай суммы и курсы.
3. Проверяй возможные дубли в Google Таблице: дата, назначение, магазин/номер чека, сумма и валюта; одинаковая сумма сама по себе не доказывает дубль.
4. Добавь строки в соответствующий лист через подключённый Google Drive/Sheets. Стабильный уникальный ID (повторная попытка не создаёт дубль), одна фактическая оплата — одна операция.
5. Прочитай внесённые строки для проверки. При успехе короткий ответ: «Записал: ...; общая сумма ...». Не обращайся к GitHub, не обновляй `data.enc.json`, не запускай сборку APK и не проси никаких ключей.
6. Android 2.0 после одноразовой настройки OAuth обновляется при запуске или нажатии «Обновить» прямо из Google Sheets API. Не обещай пользователю, что APK синхронизирован, пока OAuth не подтверждён.

## Покупки
«Нужно купить» — не расход; писать в отдельный лист. Отметки «Куплено» в Android 2.0 меняют тот же лист после OAuth, без GitHub. Чек с фактическим списанием становится расходом; отметка в списке сама денег не списывает.
